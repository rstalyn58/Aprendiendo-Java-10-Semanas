# Agenda de Contactos — Semana 8

Aplicación web construida con Java y Vaadin Flow que permite visualizar
contactos en tarjetas. La app cuenta con una barra de navegación fija,
dos vistas principales y una cuadrícula de tarjetas con datos de contacto.

## Componentes usados esta semana

| Componente | Descripción |
|------------|-------------|
| `AppLayout` | Define la estructura principal de la app con barra superior fija visible en todas las vistas |
| `MenuBar` | Muestra los ítems de navegación en línea dentro de la barra superior |
| `H2 / H3 / Paragraph` | Jerarquía tipográfica: H2 para títulos de vista, H3 para subtítulos y Paragraph para texto descriptivo |
| `Avatar` | Representa visualmente a un contacto mostrando sus iniciales automáticas o una foto de perfil |
| `Icon` | Muestra iconos vectoriales de la biblioteca VaadinIcon junto a los datos de cada contacto |
| `Div` | Contenedor genérico usado como base para construir la tarjeta reutilizable `TarjetaContacto` |
