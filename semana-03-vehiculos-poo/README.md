# ====== Semana 3 | Vehiculos (POO) ======

° Descripcion
Programa en consola para gestionar distintos tipos de vehiculos.
Permite agregar, listar, filtrar y trabajar con vehiculos electricos.

---

° Idea general
Se usa una clase base (Vehiculo) de la que salen:
|| Auto
|| Moto
|| Camion

Algunos tambien son electricos:
|| AutoElectrico
|| MotoElectrica
