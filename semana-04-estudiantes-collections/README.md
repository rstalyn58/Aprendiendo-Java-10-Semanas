# Sistema de Estudiantes con Collections

Programa en Java para gestionar estudiantes usando el Collections Framework. Permite registrar, buscar, actualizar, eliminar, ver ranking, estadísticas e historial.

---

## Colecciones

| Coleccion                   | Rol                 |
| --------------------------- | ------------------- |
| HashMap<String, Estudiante> | Busqueda por carnet |
| TreeSet<Estudiante>         | Ranking ordenado    |
| ArrayList<String>           | Historial           |

---

## Ejecucion

```id="c1"
javac Main.java
java Main
```

---

## Funciones

* Agregar, buscar, actualizar y eliminar
* Ranking y top 5
* Filtro por carrera
* Estadisticas e historial
